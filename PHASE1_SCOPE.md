# Phase 1 acceptance scope

## Supported

- Single shared game instance
- Up to 200 registrations
- Duplicate-name rejection
- Unique player IDs and session tokens
- Lobby
- Manual admin start/pause/resume/reset
- Player reconnection by saved session
- Player WebSocket connection
- Admin WebSocket connection
- Admin player table and event feed
- Mobile-oriented UI

## Intentionally deferred to Phase 2

- 13-zone gameplay implementation
- Movement rules
- Health/attack/speed stats
- Round timer and action deadlines
- Timeout elimination
- Combat
- Items
- Events and arena hazards
- Winner calculation
